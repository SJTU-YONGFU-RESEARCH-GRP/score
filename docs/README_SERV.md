## Overview

SCORE SERV checks out the [olofk/serv](https://github.com/olofk/serv) repository under `tools/serv/` including its nested submodules. Generation writes commit-scoped outputs into `datasets/serv/<commit>/` and runs Verilator lint on all `.v` and `.sv` files under the `rtl/` directory.

### Key Features

- **Commit-scoped dataset path**: generation writes under `datasets/serv/<commit>/`.
- **Nested submodule initialization**: the install script runs `git submodule update --init --recursive` after checkout.
- **RTL directory lint**: Verilator lint is run on all Verilog/SystemVerilog files found under `rtl/` in a single invocation.
- **Lint result tracking**: result is recorded as `PASS`/`FAIL` in `serv_summary.txt`.

### Scripts Overview

1. `./scripts/install_serv.sh`: checks out the SERV repository, initializes nested submodules, and optionally installs host system packages including Verilator.
2. `./scripts/generate_serv.sh`: snapshots all RTL, writes a manifest, and runs Verilator lint on all files under `rtl/`.

### Architecture Overview

- Upstream SERV is a bit-serial RISC-V (RV32I) CPU core from Olof Kindgren, designed for minimal area.
- RTL source files live under `rtl/` and may include `servant` (a reference SoC) and `serving` support files in nested submodules.

## Installation Script

### Overview

`./scripts/install_serv.sh` prepares the `tools/serv/` checkout, initializes nested submodules, and optionally installs system dependencies via the common host-deps helper.

### Basic Usage

```bash
# Standard installation
./scripts/install_serv.sh

# Validate existing checkout only
./scripts/install_serv.sh --check-only

# Skip system package installation
./scripts/install_serv.sh --no-system-deps

# Skip Verilator package installation
./scripts/install_serv.sh --no-verilator
```

### Command-Line Options

| Option | Description |
|--------|-------------|
| `-h, --help` | Show help |
| `--check-only` | Verify that `tools/serv/rtl/` exists |
| `--no-system-deps` | Skip apt/dnf/… (same as `SERV_SKIP_SYSTEM_DEPS=1`) |
| `--no-verilator` | Do not install Verilator as part of system packages |

### What the Script Does

1. Optionally installs host system dependencies (including Verilator) via the common helper.
2. Prepares the `tools/serv/` checkout via submodule bootstrap.
3. Runs `git submodule update --init --recursive` inside `tools/serv/`; warns but does not fail if nested submodule init is incomplete.
4. Verifies that `tools/serv/rtl/` exists; exits with error if missing.

## Generation Script

### Overview

`./scripts/generate_serv.sh` creates the commit-scoped dataset directory, snapshots all RTL files, writes a manifest, and runs Verilator lint on all files under `rtl/`.

### Basic Usage

```bash
# Run generation
./scripts/generate_serv.sh
```

### What the Script Does

1. Computes the commit ID and creates `datasets/serv/<commit>/logs/` and `verification/`.
2. Snapshots all RTL from `tools/serv/` into `datasets/serv/<commit>/rtl_snapshot/serv/`.
3. Writes `manifest.json`.
4. Collects all `.v` and `.sv` files under `rtl/`.
5. Runs Verilator lint on all collected files in a single invocation from the repository root, so `servant`/`serving` includes resolve if present in the file list.
6. Writes `serv_summary.txt`.
7. Exits non-zero if lint result is `FAIL`.

## Available Designs

SERV is a single bit-serial RISC-V core. All RTL files under `rtl/` are linted together; no separate named variants are generated by the script.

## Output Organization

```text
datasets/serv/<commit>/
├── serv_summary.txt
├── manifest.json
├── logs/
│   ├── main.log
│   └── session_<timestamp>.log
├── rtl_snapshot/
│   └── serv/
└── verification/
    └── verilator_lint_rtl.log
```

## Dataset Structure

- `serv_summary.txt`: commit, dataset path, lint result, and RTL file count.
- `manifest.json`: standard SCORE manifest (project, name, commit).
- `logs/main.log`: session log from `generate_serv.sh`.
- `rtl_snapshot/serv/`: snapshot of the upstream repository RTL.
- `verification/verilator_lint_rtl.log`: Verilator lint output for all `rtl/*.v` / `rtl/*.sv` files.

## Usage Examples

```bash
# Full install then generate
./scripts/install_serv.sh
./scripts/generate_serv.sh

# Check install without modifying anything
./scripts/install_serv.sh --check-only

# Install without system package changes
./scripts/install_serv.sh --no-system-deps
./scripts/generate_serv.sh
```

## Troubleshooting

- **Symptom**: `Missing tools/serv/rtl — run install_serv.sh`.
  - **Fix**: run `./scripts/install_serv.sh` to perform the initial checkout.
- **Symptom**: `rtl/ missing` after checkout.
  - **Fix**: the checkout may be incomplete; re-run `./scripts/install_serv.sh` and verify network access.
- **Symptom**: Verilator lint fails.
  - **Fix**: inspect `datasets/serv/<commit>/verification/verilator_lint_rtl.log` for errors. Ensure Verilator is installed; re-run `./scripts/install_serv.sh` without `--no-verilator` if needed.
- **Symptom**: `Nested submodule init incomplete`.
  - **Fix**: check network access and re-run `./scripts/install_serv.sh` to retry `git submodule update --init --recursive`.
