## Overview

The DarkRISCV scripts provide a workflow for checking out the DarkRISCV RTL source and snapshotting it into a structured dataset. DarkRISCV is a compact, educational RISC-V processor written in Verilog.

### Scripts Overview

The DarkRISCV workflow consists of two main scripts:

1. **`install_darkriscv.sh`**: Prepares the `tools/darkriscv` submodule checkout and installs host build dependencies including Verilator.
2. **`generate_darkriscv.sh`**: Snapshots the `rtl/` directory, runs Verilator lint on the RTL files, and writes a summary.

### Architecture Overview

DarkRISCV's RTL lives entirely under `rtl/`. The key source file is `rtl/darkriscv.v`, the core processor implementation. The `rtl/` directory also contains a configuration header (`config.vh`) and SoC-level files.

## Installation Script

### Overview

`install_darkriscv.sh` prepares the `tools/darkriscv` submodule and verifies that `rtl/darkriscv.v` exists.

### Basic Usage

```bash
# Complete environment setup
./scripts/install_darkriscv.sh

# Check that the checkout is present without installing
./scripts/install_darkriscv.sh --check-only

# Skip host package installation
./scripts/install_darkriscv.sh --no-system-deps

# Skip Verilator installation
./scripts/install_darkriscv.sh --no-verilator
```

### Command-Line Options

| Option | Description |
|--------|-------------|
| `-h, --help` | Show help message |
| `--check-only` | Verify `tools/darkriscv/rtl` exists and exit |
| `--no-system-deps` | Skip host package installation |
| `--no-verilator` | Skip Verilator installation |

The environment variable `DARKRISCV_SKIP_SYSTEM_DEPS=1` also disables system dependency installation.

### What the Script Does

1. Installs host build dependencies via `score_simple_install_host_deps` (unless skipped).
2. Prepares the `tools/darkriscv` submodule checkout via `score_prepare_tool_checkout`.
3. Verifies `tools/darkriscv/rtl/darkriscv.v` exists before exiting.

## Generation Script

### Overview

`generate_darkriscv.sh` snapshots the `rtl/` directory and runs Verilator lint on all `.v` files found at the top level of `rtl/`. Lint uses the `rtl/` directory as an include path so that `config.vh` is found.

### Basic Usage

```bash
# Snapshot RTL and run lint
./scripts/generate_darkriscv.sh
```

The script takes no command-line options.

### What the Script Does

1. Reads the current commit hash from `tools/darkriscv`.
2. Creates `datasets/darkriscv/<commit_id>/logs/` and `verification/`.
3. Snapshots the `rtl/` directory via `score_simple_snapshot_rtl`.
4. Writes `manifest.json` with project metadata.
5. Collects all `.v` files from `rtl/` (max depth 1).
6. Runs `score_simple_verilator_lint` with `-I.` on all discovered RTL files. Lint failure is non-fatal (the result is recorded in the summary).
7. Writes `darkriscv_summary.txt` and exits non-zero only if lint result is `FAIL`.

## Available Designs

DarkRISCV is a single parameterized design. The snapshot captures the complete `rtl/` tree at the checked-out commit. There are no pre-defined configuration variants generated by the SCORE scripts; any configuration is controlled by `rtl/config.vh` at elaboration time.

## Output Organization

### Directory Structure

```
datasets/darkriscv/
└── <commit_id>/
    ├── rtl_snapshot/
    │   └── darkriscv/       (contents of tools/darkriscv/rtl/)
    ├── logs/
    │   ├── main.log
    │   └── session_<timestamp>.log
    ├── verification/
    │   └── verilator_lint_rtl.log
    ├── manifest.json
    └── darkriscv_summary.txt
```

### Summary File

`darkriscv_summary.txt` contains:

```
darkriscv SCORE snapshot (darklife/darkriscv)
Commit: <short_sha>
Dataset: <absolute_path>
Lint: PASS | FAIL | SKIPPED
RTL files: <count>
```

## Dataset Structure

### Manifest Format

`manifest.json` is written by `score_simple_write_manifest` and records:

```json
{
  "project": "darklife/darkriscv",
  "name": "darkriscv",
  "commit": "<commit_id>"
}
```

## Usage Examples

### Basic Workflow

```bash
# 1. Install submodule and host deps
./scripts/install_darkriscv.sh

# 2. Snapshot RTL and lint
./scripts/generate_darkriscv.sh

# 3. Inspect results
ls datasets/darkriscv/
cat datasets/darkriscv/<commit_id>/darkriscv_summary.txt
cat datasets/darkriscv/<commit_id>/verification/verilator_lint_rtl.log
```

### Skip System Deps

```bash
./scripts/install_darkriscv.sh --no-system-deps
./scripts/generate_darkriscv.sh
```

### Check Existing Installation

```bash
./scripts/install_darkriscv.sh --check-only
```

## Troubleshooting

**Problem**: `rtl/darkriscv.v missing` during install
```
Cause:  The submodule checkout did not complete.
Fix:    Remove tools/darkriscv and re-run install_darkriscv.sh.
```

**Problem**: `Missing tools/darkriscv/rtl — run install_darkriscv.sh`
```
Cause:  generate_darkriscv.sh was run before install_darkriscv.sh.
Fix:    Run ./scripts/install_darkriscv.sh first.
```

**Problem**: Lint result is `FAIL`
```
Cause:  Verilator found syntax or semantic errors in the RTL.
Fix:    Inspect datasets/darkriscv/<commit>/verification/verilator_lint_rtl.log.
        Ensure Verilator version compatibility with the checked-out RTL.
```

### Getting Help

- Check install log: `logs/install_darkriscv/`
- Check generation log: `datasets/darkriscv/<commit>/logs/main.log`
- Use `--help` on the install script for option summary
