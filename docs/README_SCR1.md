## Overview

SCORE SCR1 checks out the [syntacore/scr1](https://github.com/syntacore/scr1) repository under `tools/scr1/` including its nested submodules. Generation writes commit-scoped outputs into `datasets/scr1/<commit>/` and runs Verilator lint using the upstream simulation filelist when available.

### Key Features

- **Commit-scoped dataset path**: generation writes under `datasets/scr1/<commit>/`.
- **Nested submodule initialization**: the install script runs `git submodule update --init --recursive` after checkout.
- **Filelist-driven lint**: if a `sim/*.f` filelist is found, Verilator lint is driven by it with `-Isrc -Isrc/includes`.
- **Verilator lint verification**: lint result is recorded as `PASS`/`FAIL`/`SKIPPED` in `scr1_summary.txt`.

### Scripts Overview

1. `./scripts/install_scr1.sh`: checks out the SCR1 repository, initializes nested submodules, and optionally installs host system packages including Verilator.
2. `./scripts/generate_scr1.sh`: snapshots all RTL, writes a manifest, and runs Verilator lint using the upstream `sim/*.f` filelist.

### Architecture Overview

- Upstream SCR1 is an open-source RISC-V (RV32IMC) processor core from Syntacore.
- RTL source files live under `src/` with headers in `src/includes/`.
- The repository provides simulation filelists under `sim/` that are used to drive the lint step.

## Installation Script

### Overview

`./scripts/install_scr1.sh` prepares the `tools/scr1/` checkout, initializes nested submodules, and optionally installs system dependencies via the common host-deps helper.

### Basic Usage

```bash
# Standard installation
./scripts/install_scr1.sh

# Validate existing checkout only
./scripts/install_scr1.sh --check-only

# Skip system package installation
./scripts/install_scr1.sh --no-system-deps

# Skip Verilator package installation
./scripts/install_scr1.sh --no-verilator
```

### Command-Line Options

| Option | Description |
|--------|-------------|
| `-h, --help` | Show help |
| `--check-only` | Verify that `tools/scr1/src/` exists |
| `--no-system-deps` | Skip apt/dnf/… (same as `SCR1_SKIP_SYSTEM_DEPS=1`) |
| `--no-verilator` | Do not install Verilator as part of system packages |

### What the Script Does

1. Optionally installs host system dependencies (including Verilator) via the common helper.
2. Prepares the `tools/scr1/` checkout via submodule bootstrap.
3. Runs `git submodule update --init --recursive` inside `tools/scr1/`; warns but does not fail if nested submodule init is incomplete.
4. Verifies that `tools/scr1/src/` exists; exits with error if missing.

## Generation Script

### Overview

`./scripts/generate_scr1.sh` creates the commit-scoped dataset directory, snapshots all RTL files, writes a manifest, and runs Verilator lint via the upstream simulation filelist.

### Basic Usage

```bash
# Run generation
./scripts/generate_scr1.sh
```

### What the Script Does

1. Computes the commit ID and creates `datasets/scr1/<commit>/logs/` and `verification/`.
2. Snapshots all RTL from `tools/scr1/` into `datasets/scr1/<commit>/rtl_snapshot/scr1/`.
3. Writes `manifest.json`.
4. Collects all `.sv`, `.v`, and `.svh` files under `src/`; exits with error if none are found.
5. Searches for `*.f` filelists under `sim/`; if found, runs Verilator lint with `-Isrc -Isrc/includes -f <filelist>`.
6. If no `sim/*.f` filelist is found, skips Verilator lint and sets result to `SKIPPED`.
7. Writes `scr1_summary.txt`.
8. Exits non-zero if lint result is `FAIL`.

## Available Designs

SCR1 is a single parameterizable RISC-V core. All design variants are driven by the same source under `src/`; no separate named config variants are generated by the script.

## Output Organization

```text
datasets/scr1/<commit>/
├── scr1_summary.txt
├── manifest.json
├── logs/
│   ├── main.log
│   └── session_<timestamp>.log
├── rtl_snapshot/
│   └── scr1/
└── verification/
    └── verilator_lint_src.log  (when sim/*.f present)
```

## Dataset Structure

- `scr1_summary.txt`: commit, dataset path, lint result, and SV/V file count.
- `manifest.json`: standard SCORE manifest (project, name, commit).
- `logs/main.log`: session log from `generate_scr1.sh`.
- `rtl_snapshot/scr1/`: snapshot of the upstream repository RTL.
- `verification/verilator_lint_src.log`: Verilator lint output when a `sim/*.f` filelist was found.

## Usage Examples

```bash
# Full install then generate
./scripts/install_scr1.sh
./scripts/generate_scr1.sh

# Check install without modifying anything
./scripts/install_scr1.sh --check-only

# Install without system package changes
./scripts/install_scr1.sh --no-system-deps
./scripts/generate_scr1.sh
```

## Troubleshooting

- **Symptom**: `Missing tools/scr1/src — run install_scr1.sh`.
  - **Fix**: run `./scripts/install_scr1.sh` to perform the initial checkout.
- **Symptom**: `No SystemVerilog/Verilog under src/`.
  - **Fix**: the checkout may be incomplete; re-run `./scripts/install_scr1.sh` and check that `tools/scr1/src/` is populated.
- **Symptom**: `No sim/*.f filelist found; skipping Verilator lint`.
  - **Fix**: this is informational — the RTL snapshot is still written. If lint is required, check whether the upstream repository provides a filelist in `sim/` for the checked-out commit.
- **Symptom**: Verilator lint fails.
  - **Fix**: inspect `datasets/scr1/<commit>/verification/verilator_lint_src.log` for lint errors. Ensure Verilator is installed; re-run `./scripts/install_scr1.sh` without `--no-verilator` if needed.
- **Symptom**: `Nested submodule init incomplete`.
  - **Fix**: check network access and re-run `./scripts/install_scr1.sh` to retry `git submodule update --init --recursive`.
