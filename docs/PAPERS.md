## Curation Notes

- Entries are grouped by survey role rather than by strict chronology.
- When the same work appears in multiple versions (for example workshop paper plus arXiv extension), the index keeps the most useful versions but avoids redundant rows where possible.
- MDPI and IEEE Access venues are excluded by project policy.
